## 🎯 核心目标

**蒸馏一个 7B 参数规模的小模型，深度掌握俄罗斯钓鱼4（Russian Fishing 4）的游戏知识。**

这涉及两个维度的能力：
1. **通用蒸馏能力** — 从大模型（Teacher）中提取知识，压缩到小模型（Student）
2. **领域知识注入** — 让模型掌握 RF4 的特定知识（钓点、鱼种、装备、机制）
