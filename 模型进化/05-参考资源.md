## 🧪 实验追踪

建议使用 **Wandb** 或 **MLflow** 记录实验：

```python
# wandb 配置示例
wandb.init(
    project="rf4-distillation",
    config={
        "base_model": "Qwen2.5-7B-Instruct",
        "method": "LoRA",
        "lora_r": 64,
        "lora_alpha": 128,
        "learning_rate": 2e-4,
        "epochs": 3,
        "dataset_size": 10000,
        "teacher_model": "gpt-4o-2024-08-06"
    }
)
```

记录每次实验的：
- 超参数配置
- 训练/验证 loss 曲线
- RF4 测试集准确率
- 生成样本质量
