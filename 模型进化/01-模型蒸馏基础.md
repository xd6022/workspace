# 01 — 模型蒸馏基础

## 1. 什么是知识蒸馏（Knowledge Distillation）

知识蒸馏由 Geoffrey Hinton 等人在 2015 年提出（论文：*Distilling the Knowledge in a Neural Network*），核心思想是：

> **用一个大型、训练充分的"教师模型"（Teacher）来指导一个小型"学生模型"（Student）的学习，使小模型在保持较小体积的同时，尽可能接近大模型的性能。**

直觉类比：大学教授（Teacher）把知识浓缩成讲义教给本科生（Student），本科生虽然经验不如教授，但掌握了精华后也能解决大部分问题。

---

## 2. 为什么需要蒸馏

| 动机 | 说明 |
|------|------|
| **推理成本** | GPT-4/Claude 等大模型推理极贵，7B 模型可在单卡运行 |
| **延迟** | 小模型推理快 10-100 倍，适合实时场景 |
| **部署** | 7B 可部署在边缘设备/手机，大模型不行 |
| **隐私** | 本地运行，数据不出域 |
| **领域特化** | 通用大模型+领域蒸馏 = 领域专家小模型 |

---

## 3. 蒸馏的核心原理

### 3.1 软标签（Soft Labels）vs 硬标签（Hard Labels）

```
硬标签（传统训练）：
  输入: "俄罗斯钓鱼4里鲤鱼用什么饵？"
  标签: "用玉米粒或面团饵"  ← one-hot，只有一个正确答案

软标签（蒸馏）：
  输入: "俄罗斯钓鱼4里鲤鱼用什么饵？"
  Teacher输出概率分布:
    玉米粒:    0.62  ← 最高
    面团饵:    0.21
    蚯蚓:      0.08
    红虫:      0.05
    亮片:      0.01
    ...       ↓
              这些"错误答案"的概率也包含信息！
              Teacher告诉我们"蚯蚓比亮片更接近正确答案"
```

**软标签的价值**：Teacher 输出的完整概率分布包含了类别之间的相似性关系，这是纯硬标签所没有的"暗知识"（Dark Knowledge）。

### 3.2 温度系数（Temperature, T）

在 softmax 中引入温度参数 T：

```
软目标概率: p_i = exp(z_i / T) / Σ exp(z_j / T)

T = 1:  正常 softmax（尖锐分布）
T > 1:  分布更平滑，"软化"了 Teacher 的输出
T → ∞: 均匀分布（无信息）
T → 0: 趋于 one-hot
```

**为什么要升温**：高温让概率分布更平滑，暴露更多类别间的关系信息。比如 T=1 时 Teacher 可能输出 `[0.98, 0.01, 0.01]`，T=5 时变成 `[0.65, 0.20, 0.15]`——学生能学到更多。

### 3.3 损失函数

```
总损失 = α × 硬标签损失 + (1-α) × 软标签损失

硬标签损失: CrossEntropy(Student输出, 真实标签)     × T²
软标签损失: KL散度(Student输出/T, Teacher输出/T)     × T²
                                           ↑
                                    T² 缩放确保梯度数量级一致
```

- **α（alpha）**：控制两个损失的权重，通常 0.1-0.5 之间
- **T² 缩放**：因为除以 T 缩小了梯度，需要用 T² 补偿

## 4. 蒸馏的种类

### 4.1 离线蒸馏（Offline Distillation）⭐ 最常用

```
1. 先训练/准备好 Teacher 模型（冻结）
2. 用 Teacher 生成软标签
3. 训练 Student 模型，同时使用真实标签和软标签
```

**优点**：简单、可控、Teacher 可复用
**这就是我们 RF4 蒸馏要用到的方式**

### 4.2 在线蒸馏（Online Distillation）

Teacher 和 Student 同时训练，互相学习。

### 4.3 自蒸馏（Self-Distillation）

Teacher 和 Student 是同一个网络，用深层指导浅层，或多代迭代。

---

## 5. 关键概念总结

| 概念 | 一句话解释 |
|------|-----------|
| **Teacher Model** | 大模型，提供"标准答案"和软标签 |
| **Student Model** | 小模型，要被训练的目标 |
| **Soft Label** | Teacher 输出的概率分布（非 one-hot） |
| **Hard Label** | 真实的正确答案标签 |
| **Temperature** | 控制概率分布平滑度的超参数 |
| **Dark Knowledge** | 隐藏在软标签中、one-hot 无法表达的相似性知识 |
| **KL Divergence** | 衡量两个概率分布差异的指标 |

## 6. 数学附录

### KL 散度

```
KL(P || Q) = Σ P(i) × log(P(i) / Q(i))
```

衡量用分布 Q 近似分布 P 时的信息损失。在蒸馏中：
- P = Teacher 的软标签分布
- Q = Student 的预测分布
- 目标：最小化 KL(P || Q)

### 蒸馏损失完整形式

```
L_total = α × CE(y_true, σ(z_s)) × T²
        + (1-α) × KL(σ(z_t/T), σ(z_s/T)) × T²

其中: σ = softmax, z_s = Student logits, z_t = Teacher logits
```
