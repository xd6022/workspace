## 二、基座模型选择（Student）

### 2025-2026 年推荐的 7B 级基座模型

| 模型 | 参数量 | 上下文 | 中文能力 | 推荐度 | 备注 |
|------|--------|--------|---------|--------|------|
| **Qwen2.5-7B-Instruct** | 7.6B | 128K | ⭐⭐⭐⭐⭐ | 🔥首选 | 中文最强，指令遵循好 |
| **Qwen3-8B** | 8B | 128K | ⭐⭐⭐⭐⭐ | 🔥首选 | 最新一代 |
| **LLaMA-3.1-8B-Instruct** | 8B | 128K | ⭐⭐⭐ | ⭐ | 英文强，中文可 |
| **Mistral-7B-Instruct-v0.3** | 7.3B | 32K | ⭐⭐ | ⭐ | 英文为主 |
| **Yi-1.5-6B-Chat** | 6B | 4K | ⭐⭐⭐⭐ | ⭐ | 中文好，但短上下文 |
| **DeepSeek-Coder-7B** | 7B | 16K | ⭐⭐⭐ | ⭐ | 如果涉及游戏数据分析 |

**推荐：Qwen2.5-7B-Instruct 或 Qwen3-8B**

理由：
- 中英文双语能力突出（RF4 资料中英文混合）
- 指令遵循能力强，适合 SFT
- 通义千问生态成熟，工具链完善
- 上下文窗口大（128K），可以塞更多游戏资料

### 3.4 数据生成策略

```python
# 使用 API 批量生成数据的伪代码框架

import openai
import json

# 种子知识片段（你先手动整理 50-100 条）
seed_knowledge = [
    "琥珀湖是鲤鱼主要钓点，水深3-8米...",
    "浮子钓需要根据水流选择浮子重量...",
    # ...
]

# 用种子知识生成多样化的 QA 对
prompt_template = """
你是 RF4 游戏专家。根据以下知识点，生成 5 个不同难度、不同问法的 QA 对。

知识点：{knowledge}

要求：
- 覆盖不同难度（新手/进阶/专家）
- 问题要有多样性（What/How/Why/Compare）
- 包含具体的数字、地点、装备名称
- 回答要详细，包含推理过程
- 用中文回答，保留英文专有名词

输出 JSON 格式：[{{"instruction": "...", "output": "..."}}]
"""

# 批量调用 API 生成
for knowledge in seed_knowledge:
    response = openai.chat.completions.create(
        model="gpt-4o",  # 或 deepseek-chat
        messages=[{"role": "user", "content": prompt_template.format(knowledge=knowledge)}],
        temperature=0.8  # 稍高的温度增加多样性
    )
    # 解析并保存
```

## 四、训练流程

### 4.1 LoRA 微调（推荐方案）

```python
# train_lora.py
from transformers import (
    AutoModelForCausalLM, AutoTokenizer,
    TrainingArguments, Trainer, DataCollatorForLanguageModeling
)
from peft import LoraConfig, get_peft_model, TaskType
from datasets import load_dataset

# ========= 1. 加载模型 =========
model_name = "Qwen/Qwen2.5-7B-Instruct"  # 或本地路径

model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype=torch.bfloat16,   # 节省显存
    device_map="auto",
    trust_remote_code=True
)

tokenizer = AutoTokenizer.from_pretrained(model_name, trust_remote_code=True)
tokenizer.pad_token = tokenizer.eos_token

# ========= 2. LoRA 配置 =========
lora_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=64,                     # LoRA rank，64 比较均衡
    lora_alpha=128,           # 缩放因子
    lora_dropout=0.1,         # 防止过拟合
    target_modules=[          # 对 Qwen2.5 的注意力层
        "q_proj", "k_proj", "v_proj", "o_proj",
        "gate_proj", "up_proj", "down_proj"
    ]
)

model = get_peft_model(model, lora_config)
model.print_trainable_parameters()
# 预期：trainable params ~ 2-5% 总参数

# ========= 3. 数据处理 =========
def format_chat(example):
    """格式化为 ChatML 格式"""
    messages = [
        {"role": "system", "content": "你是俄罗斯钓鱼4专家助手"},
        {"role": "user", "content": example["instruction"]},
        {"role": "assistant", "content": example["output"]}
    ]
    text = tokenizer.apply_chat_template(
        messages, tokenize=False, add_generation_prompt=False
    )
    return {"text": text}

dataset = load_dataset("json", data_files="rf4_data.jsonl")
dataset = dataset.map(format_chat)

def tokenize(examples):
    return tokenizer(
        examples["text"],
        truncation=True,
        max_length=2048,
        padding=False
    )

tokenized_dataset = dataset.map(tokenize, batched=True, remove_columns=["text"])

# ========= 4. 训练配置 =========
training_args = TrainingArguments(
    output_dir="./rf4-qwen-lora",
    num_train_epochs=3,
    per_device_train_batch_size=4,     # 24GB 显存可用 batch=4
    gradient_accumulation_steps=8,      # 等效 batch_size=32
    learning_rate=2e-4,                # LoRA 可以稍高
    warmup_ratio=0.03,
    lr_scheduler_type="cosine",
    logging_steps=10,
    save_steps=200,
    save_total_limit=3,
    bf16=True,                          # 开启 bf16
    gradient_checkpointing=True,        # 节省显存
    report_to="wandb",                  # 可选
    run_name="rf4-distill-v1"
)

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset["train"],
    data_collator=DataCollatorForLanguageModeling(
        tokenizer=tokenizer, mlm=False
    ),
)

# ========= 5. 开始训练 =========
trainer.train()
trainer.save_model("./rf4-qwen-lora-final")
```

### 4.2 使用 TRL 库的 SFTTrainer（更简单）

```python
from trl import SFTTrainer, DataCollatorForCompletionOnlyLM
from transformers import TrainingArguments
from datasets import load_dataset

# 数据格式：只计算 assistant 部分的 loss
response_template = "<|im_start|>assistant"
collator = DataCollatorForCompletionOnlyLM(
    response_template=response_template,
    tokenizer=tokenizer
)

trainer = SFTTrainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset["train"],
    formatting_func=format_chat,
    data_collator=collator,
    max_seq_length=2048,
)

trainer.train()
```

### 4.3 训练超参数速查

| 参数 | LoRA | QLoRA | 全参微调 |
|------|------|-------|---------|
| Learning Rate | 1e-4 ~ 5e-4 | 1e-4 ~ 5e-4 | 5e-6 ~ 2e-5 |
| Batch Size (effective) | 32-128 | 32-64 | 8-32 |
| Epochs | 3-5 | 3-5 | 2-3 |
| LoRA r | 16-128 | 16-64 | - |
| LoRA alpha | r × 2 | r × 2 | - |
| Optimizer | AdamW 8bit | AdamW 8bit | AdamW |
| Max Seq Length | 2048-4096 | 2048-4096 | 2048 |

### 5.2 人类评估标准

| 维度 | 评估标准 |
|------|---------|
| **准确性** | 信息是否与游戏实际相符 |
| **完整性** | 是否覆盖了问题的关键方面 |
| **实用性** | 建议是否可操作 |
| **一致性** | 不同时刻的回答是否自洽 |

### 5.3 评测基准文件

```
测试集设计原则：
├── 知识覆盖（鱼种×20，地图×10，装备×15，机制×20）
├── 难度分层（新手10题，进阶10题，专家5题）
├── 题型多样（事实查询、计算推理、策略建议、对比分析）
└── 避免训练集泄漏
```
